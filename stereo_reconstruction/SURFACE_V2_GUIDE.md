# 법선 개선 v2: 깊이 연결 이웃과 강건한 국소 평면

기본 estimate_surface가 connected_huber_inverse_depth_plane_v2로 변경되었습니다.
외부 법선 추정 라이브러리는 사용하지 않습니다. NumPy 행렬 연산으로 직접 구성한
경계 연결 탐색, 가중 최소제곱, Huber IRLS를 수행합니다.
기존 계산은 `estimate_surface(..., method='legacy')`로 재현할 수 있습니다.
STP1/SRF1의 바이너리 크기·필드·ID·좌표계·WebSocket 협상은 변경하지 않습니다.

## 변경 이유와 계산

기존 네 이웃의 차분은 한 픽셀의 깊이 노이즈에 민감하고 수평/수직 이웃 중 한 축이
없으면 법선을 구할 수 없었습니다. 단순히 무효 기준을 낮추거나 깊이 영상을 흐리게 하지 않습니다.

1. 각 점 주변 7×7 영역을 구성합니다. 결측 픽셀을 만들거나 채우지 않습니다.
2. 상하좌우 이웃이 모두 유효하고 기존과 같은 깊이 조건을 통과할 때만 연결합니다:
   `abs(z1-z2) <= 0.02m + 0.03*min(z1,z2)`.
3. 중심에서 이 연결을 따라 도달할 수 있는 점만 사용합니다. 영역 안에 있어도
   다른 깊이 층 또는 끊어진 점이면 제외됩니다. 구멍은 건너뛰지 않지만 같은 표면의 연결 경로로 우회할 수 있습니다.
4. 평면에서는 pinhole 영상의 역깊이가 `1/z = a*u + b*v + c`인 점을 이용합니다.
   중심 깊이로 정규화한 역깊이와 중심 기준 픽셀 좌표로 수치적으로 안정적인 3변수 회귀를 구성합니다.
5. 공간 Gaussian 가중치(sigma=2pixel)와 Huber IRLS 3회로 이상치 영향을 줄입니다.
   오차 크기는 연결된 이웃의 절대 잔차 중앙값으로 정하고, Huber 계수는 1.345입니다.
6. 최소 8개 관측, 가중 설계행렬 고유값 비율 >0.01, 상대 역깊이 RMS <=0.025가 필요합니다.
   선 위에만 놓인 관측은 충분한 2D 지지가 없으므로 거절합니다.
7. 기존 XYZ/UV로 pinhole ray 변환을 구하고 회귀 평면의 계수를 카메라 법선으로 변환합니다.
   관측 카메라를 향하게 정규화합니다. 기존 시선 cosine >=0.15 조건을 유지합니다.
8. 평면 적합이 실패하면 기존 차분 결과로 돌아갑니다. 기존 유효점이 이 이유로 사라지지 않습니다.
   기존도 무효라면 그대로 무효입니다. 고립된 점에 가짜 법선을 부여하지 않습니다.
9. splat 반경은 적합 평면의 픽셀 방향 접선으로 계산합니다. 중심 XYZ는 이동하지 않습니다.
   경계에서 반경을 제한하고 0.15m 상한을 유지합니다. voxel 빈틈을 덮도록 확대하지 않습니다.

정확한 경계는 입력 깊이의 정확성에 달려 있습니다. 완만한 곡면이나 얇은 세부 구조는 7×7
평면 가정으로 평탄해질 수 있습니다. 모든 실제 물체 경계 보존을 보장하는 방법은 아닙니다.

## 동일한 실제 스테레오 결과 비교

KITTI frame 0의 기존 `stereo_metric` 결과 73,229개 XYZ/UV/RGB를 그대로 사용했습니다.
SGM 재추정·포인트 추가·삭제·깊이 평활화를 하지 않았으며 point_cloud.npy SHA256이 같습니다.

| 지표 | v1 차분 | v2 강건 평면 |
|---|---:|---:|
| 유효 법선 수 | 39,881 | 54,491 |
| 유효 비율 | 54.46% | 74.41% |
| 공통 이웃 각도 차이 중앙값 | 30.49° | 9.15° |
| 공통 이웃 각도 차이 90백분위 | 99.51° | 39.27° |
| 표면 계산 시간 (한 실행) | 0.074초 | 1.485초 |

각도 비교는 두 방식 모두 유효하고 깊이가 연속적인 **동일한 58,587쌍**으로 계산했습니다.
이는 실제 법선 정답 오차가 아닌 노이즈/연속성의 대리지표이며 곡률 변화도 포함할 수 있습니다.
시간은 동일 환경에서 한 번 측정한 값이고 SGM·입출력 시간을 제외합니다.

## 정답 법선이 있는 합성 검증

서로 방향과 깊이가 다른 두 평면에 깊이 표준편차 0.4%의 노이즈, 약 12% 결측을 적용했습니다.
난수 seed=42, 유효 관측 4,507개, 깊이 경계 양쪽 3픽셀 폭의 관측 330개입니다.

| 지표 | v1 | v2 |
|---|---:|---:|
| 유효 비율 | 96.47% | 99.87% |
| 정답 법선 오차 중앙값 | 33.86° | 4.82° |
| 정답 법선 오차 90백분위 | 55.63° | 8.98° |
| 경계 부근 정답 법선 오차 중앙값 | 34.48° | 4.73° |
| 경계 부근 유효 관측 | 304/330 | 329/330 |

오차는 각 방식의 유효 관측에서 계산합니다. 추가 자동 테스트는 공통 유효 관측에서도
오차 감소를 검사하고, 노이즈 없는 서로 다른 방향의 평면이 깊이 경계에서 혼합되지 않는지 검사합니다.

## 출력과 B 전달

- `surface.bin / surface.npz / surface.ply`: 새 법선·반경. point_id는 원래 점과 동일.
- `surface.json.estimator`: connected_huber_inverse_depth_plane_v2.
- `surface.json.robust_parameters`: 창 크기, 반복 횟수, 잔차 한계.
- 비교 결과의 `fit_diagnostics.npz`: plane_fitted, neighborhood_count, relative_plane_residual.
  `plane_fitted=false`는 기존 차분으로 fallback했거나 최종 무효입니다. SRF1 flags bit0으로 최종 유효성을 확인합니다.
- SRF1 `support`는 여전히 상하좌우 즉시 연결 이웃 수/4입니다.
  새 평면의 이웃 개수 또는 통계적 신뢰도로 해석하지 않습니다.
- 메타데이터 estimator가 없는 과거 결과도 verify_surface.py에서 legacy 방법으로 검증합니다.

## 실행

새 dense_reconstruct / kitti_pipeline 실행은 기본적으로 v2를 사용합니다.
기존 비교용 결과 폴더를 보존한 상태에서:

```bash
python benchmark_surface.py --source /path/to/old_stereo_metric --output /path/to/comparison
python verify_surface.py --run /path/to/comparison/improved
python -m unittest discover -s tests
```

비교 그림의 위쪽은 v1, 아래쪽은 v2이며 동일 조명·색상 범위를 사용합니다.
CPU Lambert 진단 그림이고 B의 GLSL 렌더러 구현 결과는 아닙니다.
