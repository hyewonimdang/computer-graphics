# B · 스테레오 표면 렌더러

저장소 루트에서 실행합니다. 먼저 [Python 환경 설정](../README.md#시작하기)을 마치고 KITTI 첫 프레임으로 렌더러 입력을 생성합니다. 이미 A에서 생성한 프레임이 있으면 아래의 FRAME_DIR을 그 경로로 지정하세요.

```sh
(cd stereo_reconstruction && python download_kitti_sample.py --output data/kitti --frames 0 && python kitti_pipeline.py --root data/kitti --frames 0 --output runs/kitti_frame0)
npm ci --prefix renderer
FRAME_DIR=stereo_reconstruction/runs/kitti_frame0/frames/0000000000
mkdir -p renderer/data
cp "$FRAME_DIR/frame.json" "$FRAME_DIR/new_points.bin" "$FRAME_DIR/surface.bin" renderer/data/
python3 -m http.server 8724 --bind 127.0.0.1
```

브라우저에서 [렌더러 열기](http://127.0.0.1:8724/renderer/). 세 입력 파일은 같은 프레임에서 가져옵니다. 새 점만 저장된 후속 프레임은 그 프레임의 증분만 표시합니다.

A의 공식 디코더로 두 payload를 읽고 개수와 point_id 순서를 대조합니다. 위치와 법선은 (X,−Y,−Z)로 변환하며 반경은 미터 그대로 사용합니다. 초기 카메라는 frame.json의 K_rect와 카메라 포즈를 사용합니다.

Three.js는 GPU 버퍼·카메라·드로 호출과 마우스 조작을 담당합니다. splats.js의 GLSL은 각 인스턴스의 접평면과 원형 경계, 확산광과 정반사를 계산합니다. 법선 모드의 RGB는 뷰어 월드 좌표의 단위 법선을 [0,1]로 매핑한 값입니다. 무효 법선은 모든 모드에서 원래 색의 작은 점으로 표시합니다.

C의 paint.js가 착지 시각과 비행 시간을 정하면 viewer.js가 타임라인을 갱신하고 splats.js의 셰이더가 비행과 착지, 건조를 계산합니다.

### 표면 효과 비교
일시정지 후 조명 splat 모드에서 비교합니다. 세 체크박스는 각각 독립적이며 기본값은 꺼짐입니다. 확대는 유효한 원판 반경에만 1~3배를 곱합니다. 블렌딩은 가장 앞의 깊이를 먼저 구한 뒤 그 표면에서 1.5 cm 또는 깊이의 0.3% 중 큰 값 이내인 조각의 선형 RGB를 중심 가중 평균합니다. EDL은 주변 네 방향의 깊이 차이로 뒤쪽 표면을 어둡게 합니다. 배경은 음영 계산에서 제외합니다. 두 후처리는 단일 샘플 렌더 타깃을 사용하므로 기본 화면과 실루엣의 안티앨리어싱이 조금 다릅니다. 원본 점 좌표와 반경 데이터는 그대로 유지합니다.

주변 간격 기반 반경을 켜면 고정 확대를 일시 대체합니다. 끄면 이전 고정 배율 설정으로 돌아갑니다. 강도 0%는 원래 반경, 100%는 추정 반경이며 사이 값은 선형 보간합니다. 정류 UV 반경 8픽셀에서 깊이와 접평면을 검사하고 법선이 유사한 세 방향 이상의 이웃 간격으로 반경을 추정합니다. 관측된 깊이 단차까지의 거리와 원래 반경의 4배로 추가 확대를 제한합니다. 이웃이 부족하거나 법선이 없으면 원래 표현을 유지합니다. 미관측 영역의 경계까지 보장하지는 않습니다.

페인트 연출에서 붓질을 켜면 빈 화면에서 시작합니다. 정류 영상의 아래쪽부터 다섯 번 왕복하며 각 점의 원래 RGB와 XYZ로 장면을 그립니다. 입자는 붓끝 가까이에서 짧게 이동해 표면에 퍼지고 광택이 마릅니다. 시간 슬라이더로 되감거나 초반·중간·완성 버튼으로 이동할 수 있으며 10초에서 완성 화면을 유지합니다.

페인트총을 선택하면 재생이 처음부터 시작됩니다. 오른쪽 아래의 고정 총구에서 처음 여섯 발을 천천히 쏜 뒤 연사하여 장면을 채웁니다. 착지한 물감은 잠시 크게 퍼졌다 원래 크기로 가라앉습니다. 두 방식 모두 시간 슬라이더로 되감을 수 있습니다.
페인트총의 마지막 한 발은 8.10초에 출발해 9.50초에 도로에 닿습니다. 도로 위 한 발 버튼으로 멈춘 뒤 광원 위상을 바꾸면 조명과 투영 그림자가 함께 이동합니다. 착지점 접평면과 광선의 교차 위치를 구해 그 주변의 이미 그려진 같은 방향 표면에만 부드러운 음영을 적용합니다.
